{{- /* base-builder — interactive widget that turns a pasted Obsidian Base into a fill-in-the-blanks tool: a reader edits the marked fields, sees a live demo table, and downloads a ready-to-use .base file. THE BASE LIVES IN YOUR POST, NOT IN THIS WIDGET. Paste the real .base YAML as the shortcode body (open/close tags required) and mark each editable spot with a self-describing token: ${id | label=Label text | help=Tooltip text | default=Value | options=A,B} - id : unique key; the same id may appear in several places. - label : field label (defaults to id). - help : tooltip shown on the "?" (optional). - default : starting value (optional). - options : comma-separated -> renders a dropdown instead of a text box. A token may not contain the characters "}" or "|" in its values. The generated .base file is whatever you pasted with tokens filled in, so any Obsidian Bases feature passes through untouched. The live demo table renders the first view against fictional example notes (never a real vault) and understands the common filter operators (and/or/not, file.tags.contains, file.path.startsWith, file.inFolder, file.hasTag); unknown operators are treated as "match". Demo notes come from ONE of: folders - comma-separated folders inside the fake vault at static/fake-obs/, read recursively, e.g. folders="Atlas/CRM/Comp, Calendar". "/" means the whole vault. Each note's path is its real location in the fake vault, so path filters behave as in Obsidian. notes - (legacy) a flat folder under static/obs-bases-gen/; paths come from each note's `path` front-matter field. If neither is given, notes="crm-sample" is used. If both are given, folders wins. Usage (place a summary divider BEFORE the widget — see CLAUDE.md). Call it with open AND close tags; an empty body uses the built-in default base, otherwise the body is your base with tokens: base-builder (open) ... (close) base-builder notes="crm-sample" (open) ... your .base YAML ... (close) base-builder folders="Atlas/CRM/Comp, Calendar" (open) ... (close) */ -}} {{- $id := printf "bb-%d" .Ordinal -}} {{- $folders := .Get "folders" -}} {{- $notes := .Get "notes" | default "crm-sample" -}} {{- $vault := "static/fake-obs" -}} {{- /* Built-in default base (used when no body is supplied). */ -}} {{- $default := `properties: note.Specialization: displayName: specialization note.website: displayName: website views: - type: table name: ${name | label=View name | help=Shown as the view's tab in Obsidian | default=Consulting} filters: and: - file.tags.contains("${tag | label=Tag | help=Only notes with this tag; no leading # | default=consulting}") - file.path.startsWith("${path | label=Folder path prefix | help=Only notes whose path starts with this; end with a slash | default=Atlas/CRM/Comp/}") order: - file.name - rating - MBA Internship - source - tags - summary - projects - related - 2027 MBA Internship Application - tasks - Email sort: - property: file.name direction: ${dir | label=Sort direction | help=ASC or DESC | options=ASC,DESC | default=ASC}` -}} {{- $tmpl := trim .Inner "\n\r\t " -}} {{- if not $tmpl -}}{{- $tmpl = $default -}}{{- end -}} {{- /* Replace each ${id|...} token with a YAML-safe sentinel, then let Hugo parse the base at build time. The client swaps sentinels for live values when it renders the table. */ -}} {{- $sanitized := replaceRE `\$\{\s*([a-zA-Z0-9_]+)[^}]*\}` "xtokx_${1}_xtokx" $tmpl -}} {{- $doc := $sanitized | transform.Unmarshal -}} {{- /* Read the example notes at build time and inline them as JSON. */ -}} {{- $rows := slice -}} {{- $source := "" -}} {{- if $folders -}} {{- $seen := dict -}} {{- range split $folders "," -}} {{- $f := strings.Trim (trim . " ") "/" -}} {{- $dir := cond (eq $f "") $vault (printf "%s/%s" $vault $f) -}} {{- if not (os.FileExists $dir) -}} {{- errorf "base-builder: folder %q not found under %s/ (in %s)" . $vault $.Page.File.Path -}} {{- end -}} {{- range partial "base-builder-walk.html" (dict "root" $vault "rel" $f) -}} {{- $p := index . "path" -}} {{- if not (index $seen $p) -}} {{- $seen = merge $seen (dict $p true) -}} {{- $rows = $rows | append . -}} {{- end -}} {{- end -}} {{- end -}} {{- $source = $folders -}} {{- else -}} {{- $dir := printf "static/obs-bases-gen/%s" $notes -}} {{- $source = $notes -}} {{- if os.FileExists $dir -}} {{- range (os.ReadDir $dir) -}} {{- if strings.HasSuffix .Name ".md" -}} {{- $raw := os.ReadFile (printf "%s/%s" $dir .Name) -}} {{- $after := strings.TrimPrefix "---\n" $raw -}} {{- $fmText := index (split $after "\n---") 0 -}} {{- $fm := $fmText | transform.Unmarshal -}} {{- $row := merge $fm (dict "file.name" (strings.TrimSuffix ".md" .Name)) -}} {{- $rows = $rows | append $row -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}}
