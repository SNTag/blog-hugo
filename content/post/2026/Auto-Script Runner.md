Vibe-coded python script that acts as a collective auto-start option for Windows. Windows has too many fractured methods of controlling when and how programs start, and its exhausting. This GUI option also allows me to specify defaults with a certain level of complexity. You can find it [here](https://github.com/SNTag/TagOS-Manager).

![[Blog/static/images/posts/Pasted image 20260910190132.png]]

**Current Limitations**
- Windows only (I don't have any apple laptops unless someone is willing to donate)
- Requires manual starting as Windows refuses to accept it as a program.
- Not all software will start automatically. Please let me know if there are any issues.

**Benefits**
- One software to rule them all, and through the code, specify how to bind them.
